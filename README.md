# DiamondRuntime

> **This project is a hard-fork of [Winlator](https://github.com/brunodev85/winlator)**, built and maintained independently for Emerald Launcher.

[![License](https://img.shields.io/badge/license-LGPL%202.1-blue?style=flat-square)](https://github.com/utkarshdalal/GameNative/blob/master/LICENSE)

---

DiamondRuntime is a fork of Winlator designed to be used with the Emerald Launcher Android port. Made to run the Windows64 builds of LCE under Android.

## About this fork

DiamondRuntime is an independent **hard-fork of [Winlator](https://github.com/brunodev85/winlator)**, maintained by the [LCE Hub](https://github.com/LCE-Hub) project as the game runtime behind **Emerald Launcher for Android**. It adds and removes functionality as needed to serve the Emerald Launcher.

A big thank-you to the Winlator maintainers and community. Without their work this project would not exist.

## Contributing

This is a fork, so the fastest way to get help is through [GitHub issues](https://github.com/LCE-Hub/DiamondRuntime/issues). If you'd like to contribute, open a pull request against the `main` branch.
